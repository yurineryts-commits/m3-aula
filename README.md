# aula-m3-comanda · a comanda da lanchonete

Módulo 3 · POO com TypeScript · Jovem Tech 2026 · T06D

O repositório que o professor coda ao vivo com a turma. O domínio é uma lanchonete: itens do cardápio, a comanda de uma mesa, o total e o fechamento. Ele não é o produto de nenhum squad: é o lugar onde cada conteúdo aparece primeiro, para depois você levar para a sua peça e para o seu domínio de estudo.

## Como você usa

1. Clique em **Use this template → Create a new repository**, na sua conta. Nome: `m3-aula`. Visibilidade: **Public**.
2. Em **Settings → Collaborators**, adicione `DevVitorFernandes`.
3. Clone dentro da pasta do módulo, com o nome `aula`:

```
cd modulo-ts-poo
git clone <link do seu m3-aula> aula
```

Durante a aula você faz no seu `m3-aula` o mesmo que o professor faz aqui: a mesma issue, a mesma branch, o mesmo PR.

## Pastas

- `legado/` · o ponto de partida em JavaScript. `o-js-deixou-passar.js` tem quatro defeitos; `comanda.js` é a comanda que vira TypeScript ao longo do módulo.
- `dados/cardapio.json` · a resposta da "API" do cardápio. Tem defeito de propósito.
- `src/` · o código em TypeScript.
- `docs/modelo.md` · o mapa das classes da comanda.
